# Hitfit Tribe

A static marketing website for running coach Hitendra Choudhary.

## Included sections
- About
- Coaching Programs
- Testimonials
- Blog
- Contact us
- Primary CTA buttons for Start Training and Fill in the form

## Files
- `index.html` – main landing page
- `styles.css` – styling and layout
- `coach-profile.rtf` – editable rich text file for coach details

## Run locally
Open `index.html` in a browser or serve the folder with a local web server.

Example:
```bash
cd Hitfit-Tribe
python -m http.server 8000
```
Then visit: http://localhost:8000
